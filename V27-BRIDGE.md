# Pont vers Bosco v27

La v27 conserve l’application v26 adaptée à GitHub Pages et complète son jeu de ressources à partir de l’archive source `Bosco-Version-22-complete.zip`.

Éléments réintégrés :

- les poses `preparing` et `worried` ;
- les calques synchronisés de mains et de doigts manquants ;
- les métadonnées des poses et le manifeste des 40 décors ;
- les ressources de réparation, de référence et les deux livrables téléchargeables ;
- les quatre SVG publics de la source complète.

Les adaptations GitHub Pages sont conservées : préfixe `/bosco-pwa/`, manifeste iPhone, service worker et entrée React autonome.
